# WorkSafeBC design system assets (not committed)

The app's look and feel comes from the WorkSafeBC UX design system
(https://ux-static.online.worksafebc.com/, v8.1.0). Its CSS, fonts and logo are
not stored in this repository. To run the app, download them into this folder:

- `css/wsbc.css` -> `wsbc.css`
- fonts referenced by `wsbc.css` (`css/assets/fonts/*`) -> `assets/fonts/`
- `css/assets/img/worksafebc-logo.jpg` -> `assets/img/worksafebc-logo.jpg`

All from `https://ux-static.online.worksafebc.com/`. Font Awesome 4.7 comes from npm.
